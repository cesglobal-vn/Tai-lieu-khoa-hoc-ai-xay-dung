# Mẫu file bàn giao (chỉ nạp khi làm việc với thư mục handoff)

Mỗi file `handoff/NN_ten.md` có đúng 6 mục:

1. Việc được giao
2. Đầu vào đã đọc (đường dẫn file)
3. Kết quả (bảng hoặc danh sách, có nguồn từng số)
4. Giả định đã dùng
5. Chỗ chưa chắc (Cần xác nhận lại)
6. Việc người sau cần làm
